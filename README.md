Windows Event Analyzer X

Advanced Windows Event Log Analysis Tool for SOC Analysts

About the Project

Windows Event Analyzer X is a Python-based cybersecurity tool designed to analyze Windows Event Logs, identify suspicious activities, and generate security reports.

Features

- Windows Event Log Analysis
- CSV and TXT Log Parsing
- EVTX File Support
- Event ID Analysis
- Security Event Detection
- Risk Scoring
- MITRE ATT&CK Mapping
- SOC Dashboard

Technologies

- Python
- PyYAML
- python-evtx
- Git & GitHub
